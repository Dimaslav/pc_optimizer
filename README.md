# PC Optimizer + Disk Scanner

Объединённая утилита для Windows / Linux / macOS: сканер диска, анализ
размеров папок, очистка системного мусора, поиск дубликатов и больших
файлов, управление автозагрузкой и процессами.

Версия: **1.1.0**

---

## Возможности

### Сканер диска
- Рекурсивный обход с пропуском симлинков, junction и reparse points.
- Категоризация файлов: изображения, видео, аудио, документы, архивы,
  код, приложения, образы дисков, прочее.
- Дерево папок с количеством файлов и суммарным размером.
- Таблица файлов с сортировкой, поиском и фильтром по категории.
- Контекстное меню: открыть, показать в проводнике, копировать путь,
  удалить (с проверкой защиты).

### Анализ размеров папок
- Диаграмма подпапок с процентным соотношением.
- Отдельная строка «файлы в корне».
- Двойной клик — открыть папку в системном файловом менеджере.

### Очистка системы
- Категории: временные файлы, кэш миниатюр, кэши браузеров
  (Chrome / Edge / Brave / Firefox), игровые кэши, недавние документы.
- Фильтр «удалять файлы старше N часов».
- Предварительный просмотр с чекбоксами и экспортом в CSV.
- Удаление **только** после подтверждения, с отчётом в JSON.

### Корзина и DNS
- Windows: `SHQueryRecycleBinW` + `SHEmptyRecycleBinW`.
- Linux: `gio trash --empty` с ручным фолбэком.
- macOS: очистка `~/.Trash`.
- Сброс кэша DNS: `ipconfig /flushdns`, `resolvectl flush-caches`,
  `dscacheutil -flushcache`.

### Поиск дубликатов
- Двухэтапное сравнение: частичный хеш (первый + последний блок) →
  полный SHA-256.
- Учёт hard links через `(st_dev, st_ino)`.
- Ограничение на минимальный размер (МБ).

### Большие файлы
- Быстрый обход без повторных `stat()`.
- Сортировка по убыванию размера.
- Экспорт в TXT.

### Автозагрузка (Windows)
- Реестр `HKCU\...\Run` и `HKLM\...\Run` (32/64-битные представления).
- Папки Startup пользователя и `ProgramData`.
- Отключение с автоматическим бэкапом.
- Восстановление из бэкапа.

### Процессы
- Список с PID, именем, памятью, статусом и пользователем.
- Завершение с защитой критических процессов (`csrss`, `lsass`,
  `svchost`, `explorer`, `systemd`, `launchd` и др.).

### Дашборд
- Оценка здоровья системы (CPU, память, свободное место).
- Дата и результат последней очистки.
- Список предупреждений.

### Безопасность
- Защита системных путей (`Windows`, `System32`, `Program Files`,
  `/bin`, `/usr`, `/System` и т.п.).
- Защита расширений (`.dll`, `.sys`, `.drv`, `.efi` и др. — настраивается).
- Защита критических имён (`pagefile.sys`, `hiberfil.sys`, `hosts` и т.п.).
- Пользовательский список «никогда не удалять».
- Пропуск симлинков, junction и reparse points везде.
- Проверка защиты перед каждым удалением — включая таблицу сканера.
- Безопасный режим: принудительное удаление через корзину.
- Single instance через `QSharedMemory` + `QLockFile`.

## Требования

- **Python:** 3.9+ (рекомендуется 3.10 или новее).
- **ОС:** Windows 10/11, Linux (с `gio` или `xdg-open`), macOS.
- **GUI:** PyQt6.
- **Опционально:**
  - `send2trash` — для безопасного удаления в корзину.
  - `psutil` — для дашборда и вкладки «Процессы».
  - На Windows `winreg` входит в стандартную библиотеку.

## Использование

### Горячие клавиши

| Комбинация   | Действие                                     |
|--------------|----------------------------------------------|
| `F5`         | Пересканировать текущий путь                 |
| `Ctrl+F`     | Фокус в поле поиска (вкладка «Сканер диска») |

### Типичные сценарии

**Найти, что занимает место:**
1. Вкладка **Анализ папок** → выбрать диск → «Анализировать».
2. Отсортировать по размеру, двойной клик — открыть папку.

**Очистить систему:**
1. Вкладка **Очистка** → выбрать категории и возраст.
2. «Найти файлы» → проверить список → «Удалить отмеченное».

**Найти дубликаты:**
1. Вкладка **Дубликаты** → указать папки и мин. размер.
2. «Найти дубликаты» → изучить группы → экспорт.

**Отключить программу из автозагрузки (Windows):**
1. Вкладка **Автозагрузка** → выбрать элемент → «Отключить выбранное».
2. При необходимости — «Восстановить из бэкапа».

## Файлы и каталоги

Все данные хранятся в `~/.pc_optimizer/`:

```
~/.pc_optimizer/
├── config/
│   ├── settings.json          # пользовательские настройки
│   ├── startup_backups.json   # бэкапы автозагрузки
│   └── app.lock               # lock-файл single instance
├── logs/
│   └── pc_optimizer.log       # ротация 5 МБ × 3
├── reports/
│   └── cleanup_YYYYMMDD_HHMMSS.json
└── startup_backups/           # перемещённые файлы автозагрузки
```

На Windows путь: `C:\Users\<Имя>\.pc_optimizer\`.

## Настройки

Все настройки доступны во вкладке **Настройки**:

| Параметр                          | По умолчанию | Описание                                              |
|-----------------------------------|--------------|-------------------------------------------------------|
| Безопасный режим                  | включён      | Удаление только через корзину                         |
| Удалять только старше N часов     | 72           | Возраст файлов для очистки                            |
| Большие файлы от (МБ)             | 250          | Порог для вкладки «Большие файлы»                     |
| Дубликаты от (МБ)                 | 20           | Порог для поиска дубликатов                           |
| Защищённые расширения             | `.sys .dll .drv .ocx .msi .msp .efi .winmd .manifest` | Не удаляются |
| Игнорируемые папки                | `$recycle.bin, system volume information, windowsapps` | Пропускаются при обходе |
| Дополнительно защищённые папки    | —            | Список «никогда не удалять»                           |

Пустой список защищённых расширений не допускается — программа вернёт
дефолтный набор, чтобы случайно не отключить защиту.

## Безопасность удаления

Перед каждым удалением проверяется:

1. Путь не корень диска и не корень сканирования.
2. Путь находится **внутри** разрешённой папки.
3. Не является симлинком или reparse point.
4. Не входит в системные корни (`Windows`, `/usr`, `/System` и т.п.).
5. Имя не входит в список критических (`pagefile.sys`, `hosts` и т.п.).
6. Расширение не входит в список защищённых.
7. Не имеет атрибута `SYSTEM` (Windows).
8. Не входит в пользовательский список защищённых папок.

При включённом безопасном режиме удаление идёт через `send2trash`;
если пакет не установлен — операция блокируется с предупреждением.

## Решение проблем

### Программа не запускается: «Программа уже запущена»
Удалите lock-файл:
- Windows: `C:\Users\<Имя>\.pc_optimizer\config\app.lock`
- Linux/macOS: `~/.pc_optimizer/config/app.lock`

Если процесс точно не работает — удаляйте смело.

### Дашборд пуст, вкладка «Процессы» пустая
Установите `psutil`:

```bash
pip install psutil
```

### «Безопасный режим» не работает
Установите `send2trash`:

```bash
pip install send2trash
```

Либо отключите безопасный режим во вкладке «Настройки» (не рекомендуется).

### Сканер пропускает папки
Так и задумано: junction и reparse points не обходятся, чтобы избежать
зацикливания (например, `C:\Users\All Users` → `C:\ProgramData`).
Список игнорируемых папок настраивается.

### Ошибка доступа при сканировании
Нормально для системных папок. Счётчик ошибок виден в строке итогов.
Запуск от имени администратора уменьшит их количество, но **не** отменит
защиту — удаление системных файлов по-прежнему запрещено.

### На Linux нет корзины
Установите `gio` (входит в `glib2`) или `libglib2.0-bin`. Фолбэк —
ручная очистка `~/.local/share/Trash`.

## Разработка

### Тесты
На текущий момент отсутствуют. Для ручного тестирования:

```bash
python -m py_compile main.py
python main.py
```

Рекомендуется покрыть тестами:
- `validate_delete_path`, `is_protected`, `is_inside`;
- `scan_cleanup` + `delete_candidates` на временной папке;
- `partial_hash` / `full_hash` на маленьких и больших файлах;
- `Settings._coerce` на некорректных типах;
- `disable_startup` / `restore_startup` (Windows).

### Стиль
- Типизация через `from __future__ import annotations`.
- `dataclass` для структур данных.
- Потокобезопасность через `RLock`.
- Логирование через `logging.getLogger(__name__)`.

## Известные ограничения

- **Вкладка «Автозагрузка»** реализована только для Windows.
  На Linux/macOS покажет пустой список.
- **Сканер диска** хранит все файлы в памяти — на миллионах файлов
  потребление может достигать сотен МБ.
- **Поиск дубликатов** также держит индексы в памяти.
- **Hard links** не считаются дубликатами (это ожидаемое поведение),
  но **symlinks** и reparse points пропускаются.
- **Сетевые диски** в Windows не участвуют в подсчёте корзины
  (только локальные и съёмные).
